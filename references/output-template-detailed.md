# 详细评审输出模板

仅当用户明确要求详细评审、逐项评分、假设分析、MVP、指标或能力复用矩阵时使用。

## 1. 通用原则

- 结论先行；
- 大中型需求使用 7 个正式维度；
- 小型需求使用 5 个正式维度；
- 证据和假设作为横向机制；
- 阻断项优先于平均分；
- 使用普通阿拉伯数字编号；
- 不输出无依据技术、UI 或法律结论。
